# 🏐 VolleyBase

> **The Home of Volleyball.**

VolleyBase is an open volleyball platform providing live scores, player profiles, teams, competitions, standings, statistics, rankings, and developer APIs.

---

## 🌍 Projects

- 🌐 Web
- ⚙️ Admin
- 📡 API
