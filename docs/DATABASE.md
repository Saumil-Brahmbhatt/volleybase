# 🗄️ VolleyBase Database

## Philosophy

VolleyBase stores data in three categories:

- Permanent Data
- Seasonal Data
- Match Data

Changing information should **never** be stored in permanent tables.

Example:

Player
    ↓
Permanent Information

PlayerSeason
    ↓
Season Information

PlayerMatchStats
    ↓
Match Information

---

# Database Conventions

## Primary Keys

Every table has two IDs.

### Internal ID

Generated by Prisma.

```text
id
```

Example:

```text
cmf4qz7ka0000k4bs7k12j8
```

Used only internally.

---

### Public ID

Used everywhere else.

Examples:

```text
PLY000001
TEM000001
ORG000001
COM000001
SEA000001
MAT000001
VEN000001
COA000001
OFF000001
USR000001
```

### Notes

The Player table stores only permanent information.

The following fields DO NOT belong here:

- Team
- Jersey Number
- Captain
- Season Statistics
- Match Statistics

These belong in PlayerSeason or PlayerMatchStats.
